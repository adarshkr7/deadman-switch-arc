## Submission checklist

Requirements from the hackathon page:

- [ ] Built in Arc Studio from first contract to working app (projects built outside Arc Studio aren't eligible)
- [ ] Contracts written and tested in Arc Studio, deployed to **Arc mainnet** (testnet-only isn't eligible)
- [ ] Working app that calls the contracts, live at a public link
- [ ] At least one mainnet transaction that moves USDC through the contract and app
- [ ] Arc Studio project URL
- [ ] Contract address(es) plus one tx hash, linked on explorer.arc.io
- [ ] **Public** repo (this repo starts private, so switch it before submitting: `gh repo edit --visibility public --accept-visibility-change-consequences`)
- [ ] Video walkthrough showing the build in Arc Studio and the mainnet transaction
- [ ] Short description of the project and how Arc Studio was used
- [ ] Public builder profile on GitHub, X, or Farcaster

## Judging

- Real USDC moving on Arc mainnet, shown with contract addresses and tx hashes (30%)
- Use of Arc Studio across contracts, testing, and app (25%)
- A working product (25%)
- Potential to go further (20%)
